# ⛏ EPIC Launcher

Красивый и простой лаунчер для **Minecraft: Java Edition** на Windows: скачивает игру с официальных серверов Mojang, запускает её и держит всё нужное под рукой — сервера, сборки, моды и скины.

## 📥 Как установить

1. Откройте страницу релизов: **[github.com/kitlit73/EPIC_Launcher/releases/latest](https://github.com/kitlit73/EPIC_Launcher/releases/latest)**
2. Скачайте **`EPIC.Launcher.Setup.X.Y.Z.exe`** (обычный установщик) — или `EpicLauncher-X.Y.Z-win.exe`, если хотите версию «одним файлом» без установки (portable).
3. Запустите скачанный файл и следуйте шагам установщика (можно выбрать папку).
4. Откройте **EPIC Launcher** с рабочего стола и играйте.

> 💡 Windows SmartScreen может предупредить о неизвестном издателе — приложение не подписано цифровой подписью. Нажмите **«Подробнее» → «Выполнить в любом случае»**.

**Системные требования:** Windows 10/11 (64-бит), интернет. Java скачивается лаунчером автоматически — ставить её вручную не нужно. Для игры потребуется несколько ГБ на диске (сам лаунчер лёгкий, игра качается по мере запуска).

## 🚀 Быстрый старт

1. Откройте вкладку **«Аккаунты»**:
   - **⚡ Оффлайн-режим** — введите только ник и играйте (подходит для одиночной игры и серверов без лицензии);
   - **🔥 Войти через EPIC account** — ник и пароль (регистрация там же, прямо в лаунчере).
2. На **«Главной»** выберите версию игры (или оставьте последнюю) и нажмите **ИГРАТЬ**. Лаунчер сам скачает всё, что нужно, при первом запуске.
3. Хотите сразу на сервер? Нажмите плитку **🔥 EPIC** — быстрый вход на сервер одной кнопкой.

## ✨ Возможности

### 🏠 Два режима работы
- **Простой** — одна версия игры, минимум настроек: выбрал и запустил.
- **Продвинутый** — управление **сборками** (как в Prism Launcher): отдельная папка, версия, загрузчик, память и моды у каждой сборки.

### 🧩 Каталог сборок (Modrinth и FTB)
- Вкладка «Каталог сборок» на главной (в продвинутом режиме): поиск по **Modrinth** и **FTB**, установка в один клик — моды, конфиги и загрузчик поставятся сами.
- Импорт локальных сборок из файла **`.mrpack`** (Modrinth).
- Свои сборки: создание, копирование, удаление, экспорт.

### ⚒ Загрузчики модов
- **Fabric**, **Forge**, **NeoForge** и **Quilt** — устанавливаются автоматически для выбранной версии Minecraft (и при создании сборки, и при запуске).

### 🧱 Моды
- Вкладка **«Моды»**: поиск и установка модов с **Modrinth** и **CurseForge** в выбранную сборку, список установленных, удаление в один клик.

### 🖥 Сервера
- Плитка **EPIC** — мгновенный вход на сервер (порт определяется автоматически по SRV-записи).
- Свои сервера: добавьте IP — плитка появится на главной с живым пингом; при запуске лаунчер сразу подключит вас к выбранному серверу.
- Кнопка «Вписать сервера в игру» — ваши сервера появятся прямо в меню мультиплеера Minecraft.

### 🎨 Темы и фоны
- **4 фона** (Незер, Пещера, Закат на горе, Солнечная лужайка — живые CSS-сцены с параллаксом) × **4 темы** (Лава, Изумруд, Океан, Пустота) = **16 сочетаний** на вкус.

### 📦 Всё остальное
- **Автообновление**: лаунчер сам проверяет новые версии на GitHub и умеет обновляться по одной кнопке (Настройки → Обновления).
- Слайдер оперативной памяти (1–16 ГБ), аргументы JVM, полный экран.
- Автоподбор Java нужной версии (скачивается с официальных серверов Mojang).
- Живой лог запуска (Настройки → журнал), звуки в стиле Minecraft, оверлей запуска с советами.
- Оффлайн-режим работает даже без интернета (после первого запуска).

## ❓ Частые вопросы

**Где лежат файлы игры?**
`%APPDATA%\EpicLauncher\.minecraft` — как у обычного Minecraft (миры, ресурспаки, скриншоты — там же). Сборки — в `%APPDATA%\EpicLauncher\instances`.

**Антивирус ругается на установщик / лаунчер?**
Файл не имеет цифровой подписи, поэтому часть антивирусов проявляет осторожность. Добавьте лаунчер в исключения, если доверяете источнику (официальный GitHub-релиз).

**Что такое оффлайн-режим?**
Вход без аккаунта, только по нику — для игры одному или на серверах с `online-mode=false`. UUID генерируется как в ванильном оффлайн-режиме.

**Игра запустилась, а лаунчер закрыть?**
Пока игра работает, кнопка запуска превращается в **«⏹ Остановить»** — можно выключить игру из лаунчера. Лаунчер можно свернуть.

**Лаунчер пишет «Сервер EPIC недоступен»?**
Проверьте интернет; на странице «Аккаунты» есть кнопка «🔌 Проверка связи».

## 🛠 Для разработчиков

```bash
npm install     # зависимости
npm start       # запуск из исходников (Electron)
npm run dist    # сборка установщиков в dist-app/
```

Стек: Electron + чистый JS/CSS (без сборки фронтенда), модули лаунчера — в `src/` (запуск игры, загрузчики, сборки, моды, обновления).

> **Примечание:** серверная часть (EPIC account) разворачивается отдельно и в этот репозиторий **не входит** — папка `server/` игнорируется.
