# ⛏ EPIC LAUNCHER — красивый Minecraft-лаунчер

Современный веб-лаунчер Minecraft в тёмном «пиксельном» стиле: параллакс-фон с миром игры, glassmorphism-интерфейс, пиксельные аватары по нику, галерея скинов, менеджер модов, выбор версий и анимация запуска.

## Возможности
- 🏠 **Главная** — аккаунт, выбор версии (Release / Snapshot / Beta / Alpha), слайдер RAM, избранные сервера, большая кнопка «ИГРАТЬ» с прогрессом загрузки и оверлеем запуска с советами.
- 🧍 **Скины** — 6 персонажей, отрисованных на canvas; превью большого персонажа + детерминированный пиксельный аватар по нику (как face.pp).
- 📦 **Моды** — OptiFine, Fabric, Forge, Create, Iris и др. с переключателями и поиском.
- ⚙️ **Настройки** — тумблеры, аргументы JVM, каталог игры.
- 🔊 Звуки кликов в стиле Minecraft (WebAudio), тосты-уведомления, живая статистика онлайна, ротация новостей.
- 💾 Профиль (ник, скин, версия, RAM) сохраняется в localStorage.
- 📱 Адаптивная вёрстка.

## Запуск
Проект — чистый HTML/CSS/JS без сборки. Достаточно открыть index.html в браузере или поднять локальный сервер:

```bash
python3 -m http.server 8000   # затем откройте http://localhost:8000
```

## Структура
```
index.html   — разметка (страницы: Главная, Скины, Моды, Настройки)
styles.css   — тема, анимации, параллакс-сцена фона
app.js       — логика: навигация, скины/canvas, запуск игры, звук, хранение
```

> Это UI-прототип лаунчера: реальное скачивание ядра и запуск Java-процесса не выполняются — анимация загрузки имитирует настоящий пайплайн Mojang-лаунчера.
